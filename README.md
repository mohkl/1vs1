# 1vs1 — لعبة XO (الإصدار 2.0.1)

المطور: **rFM** — واتساب: https://wa.me/201027814323

تطبيق Android (Kotlin + Jetpack Compose) يعمل بدون إنترنت: لعب ضد الكمبيوتر (4 مستويات)، لعب محلي،
غرف بكود خاص حتى 6 لاعبين مع نظام تناوب عبر Wi-Fi / Hotspot / الشبكة المحلية، تحديات وإنجازات وترتيب.

## البناء والتسليم عبر GitHub
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتوى هذا المجلد إليه (فرع `main`).
2. سيعمل `Build APK` تلقائيًا (تبويب Actions) وينتج Artifact باسم `1vs1-apk`.
3. لإنشاء Release بالإصدار 2.0.1 نفّذ:
   `git tag v2.0.1 && git push origin v2.0.1`
   فيُنشئ الـ Workflow الـ Release ويرفق ملف APK، ورابطه:
   `https://github.com/<USER>/<REPO>/releases/latest`
4. رابط التحميل داخل التطبيق (QR والمشاركة) يُضبط تلقائيًا من اسم المستودع أثناء البناء.

## ملاحظات
- التوقيع بمفتاح debug ليكون APK قابلًا للتثبيت مباشرة؛ للنشر على المتاجر استخدم مفتاح إصدار خاصًا بك.
- اللعب الجماعي: يفتح المضيف غرفة (TCP 45455 + اكتشاف UDP 45454)، وينضم اللاعبون بالكود على نفس الشبكة.
  لـ Wi-Fi Direct: اربط الجهازين من إعدادات النظام أولًا ثم استخدم الكود كالمعتاد.
